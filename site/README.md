# Лендинг MeshTrack Desktop (`site/`)

Статический одностраничный сайт на русском языке. Без фреймворков и внешних
ресурсов (все стили/скрипты/картинки локальные) — работает из любого места,
где можно раздать статику.

## Локальный просмотр

```bash
open site/index.html
```

## Пересъёмка скриншотов

Скриншоты `site/assets/img/*` генерируются скриптом `tools/screenshot.py`:
приложение запускается в демо-режиме (нужны скачанные карты — центр берётся
из активной карты), снимаются главное окно, попап трекера и диалог «Управление
картами». Карты с окном сохраняются в WebP (1800 px), диалог — в PNG.

```bash
.venv/bin/python tools/screenshot.py
```

Скрипт пишет в `site/assets/img/` (файлы перезаписываются). После пересъёмки
проверьте картинки глазами — модель/CI это не делают.

## Деплой

Сайт выкладывается на собственный хостинг заказчика: достаточно залить
содержимое папки `site/` как статику (никакой сборки не требуется).
Для справки — вариант с Cloudflare Pages (бесплатно, приватный репозиторий):

1. Зарегистрируйтесь на https://dash.cloudflare.com и выберите **Workers &
   Pages → Create → Pages → Connect to Git**.
2. Разрешите доступ к репозиторию `meshtrack-desktop`.
3. Настройки сборки:
   - **Production branch:** `main`
   - **Build command:** (пусто — это статика)
   - **Build output directory:** `site`
4. **Save and Deploy** — сайт появится на `https://<project>.pages.dev`.

GitHub Pages требует публичный репозиторий (или платный Pro).

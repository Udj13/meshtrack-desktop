## Шаг 3. Headless-модуль `meshtrack/map_manager.py`

**Контекст:** логика сканирования, статусов и удаления карт должна быть чистой от Qt, чтобы её можно было тестировать headless.

**Файлы:**
- `meshtrack/map_manager.py` (новый)
- `tests/test_map_manager.py` (новый)

**Действия:**
1. Создать dataclass `MapEntry`:
   - `map_id`, `name`, `path`, `source` (config / disk / prebuilt),
   - `exists`, `size_bytes`, `tile_count`, `zmin`, `zmax`,
   - `bbox`, `tile_count_expected`, `complete`,
   - `status` (downloaded / partial / missing / orphan / not_downloaded / corrupted).
2. `scan_maps(settings, maps_dir) -> list[MapEntry]`:
   - объединяет записи из `settings.maps`, файлы в `maps_dir` и `PREBUILT_REGIONS`;
   - для существующих файлов читает метаданные через `MapStore` в try/except;
   - определяет статус по правилам из общего плана.
3. `delete_map_file(path)` — удаляет `.mbtiles`, `-wal`, `-shm` с небольшим ретраем (Windows).
4. `delete_map(settings, map_id) -> str | None`:
   - если карта активна, выбирает новую активную через `first_existing_map_id()`;
   - удаляет файл и sidecars;
   - вызывает `settings.remove_map(map_id)` и `settings.save()`;
   - возвращает новый `active_map_id` или `None`.
5. Добавить тесты: все статусы, удаление файла + sidecars, обновление активной карты.

**Проверка:**
- `pytest -q tests/test_map_manager.py` — зелёный.
- `pytest -q` — весь набор зелёный.

**Критерий завершения:** headless-логика работает и протестирована.

## Шаг 4. UI-диалог `meshtrack/map_dialog.py` и интеграция в `app.py`

**Контекст:** нужен интерфейс для просмотра списка карт и действий над ними.

**Файлы:**
- `meshtrack/map_dialog.py` (новый)
- `meshtrack/app.py`

**Действия:**
1. Создать `MapManagerDialog`:
   - `QTableWidget` с колонками: Название, Область, Зум, Размер, Тайлов, Статус, Активна;
   - кнопки «Обновить», «Скачать новый регион…»;
   - кнопки по строке в зависимости от статуса:
     - скачанная — «Сделать активной», «Удалить»;
     - частичная — «Сделать активной», «Докачать», «Удалить»;
     - отсутствующая — «Скачать заново», «Убрать из списка»;
     - осиротевшая — «Подключить», «Удалить»;

2. «Скачать новый регион…» / «Скачать» для встроенного региона — открывать `FirstRunWizard` с `preselect_region_id`.
3. «Докачать» — использовать `DownloadThread` из `first_run_wizard.py` внутри `QProgressDialog` с отменой. После успеха записать `complete=1`. Если карты не было в config — добавить через `settings.add_map`.
4. «Удалить» — `QMessageBox` с подтверждением, именем и размером; если активная — сначала `bridge.setActiveMapId(new_id)`; затем `map_manager.delete_map(...)`; обновить таблицу.
5. В `app.py`:
   - добавить пункт меню «Карта → Управление картами…»;
   - сделать `status_map` кликабельным (например, обернуть в `QPushButton`/`QLabel` + `mousePressEvent`) — открывает диалог;
   - после закрытия диалога обновлять `status_map`, сохранять настройки и пушить активную карту в JS.

**Проверка:**
- `pytest -q` — зелёный.
- Запустить приложение: карта открывается, диалог «Управление картами» открывается, переключение/удаление работает вручную.
